Features

Built like a cockpit.
Works like a chat.

Everything you expect from a modern AI chat app, inside an interface that feels like mission control.

HUD interface

An animated particle grid, a system bar with live CPU load and clock, an icon rail, a glowing composer and a holographic thinking orb.

Streaming replies

Answers stream into glass cards with Markdown, tables, syntax-highlighted code and LaTeX math — while you watch them arrive.

Reasoning you can read

Models that think show their work in a collapsible reasoning panel, along with how long they thought before answering.

Never left waiting

If a model is rate-limited, the next one answers. If they’re all busy, Orbis waits for the window to reset and retries. Every switch is logged in the activity panel.

Files and prompt help

Attach text and code files to any message. Improve prompt rewrites your draft with the Fast model before you send it.

Chats that stay put

A history drawer with search, rename and delete. Share any chat as Markdown. Stop, regenerate, edit-and-resend, rate, or have replies read aloud.

Your key stays yours

Your API key is encrypted with Windows DPAPI and never reaches the interface process. Conversations are stored on your own PC.

Make it yours

Name your assistant, tell it how to address you, write custom instructions, choose dark or light, and switch the visual effects on or off.

FAQ

Questions, answered.

Is Orbis free?

Yes. Orbis is free to download and use. It connects to the models with your own NVIDIA API key, which NVIDIA offers on a free tier for testing and evaluation — about 40 requests a minute. There is no Orbis account and nothing to subscribe to.

Where do my chats and my key go?

Your messages are sent to NVIDIA’s API to generate replies. Your chat history and settings live on your PC in %APPDATA%\Orbis. The API key is encrypted with Windows DPAPI and is only ever read by the app’s background process, never by the interface.

Windows warned me when I ran the installer. Is that normal?

Yes, for now. The installer isn’t code-signed yet, so Windows SmartScreen shows a notice the first time. Click More info, then Run anyway. Only download Orbis from this page or from the GitHub releases it links to.

Which models can I use?

Kimi K3, DeepSeek V4 Pro, Kimi K2.6, DeepSeek V4 Flash and Nemotron 3 Ultra, all through NVIDIA’s API. Auto, Fast, Advanced and Reasoning modes pick one for you; Customize lets you choose directly.

Is there a Mac or Linux version?

Not yet — Orbis ships for Windows first. It’s built with Electron, so other platforms are possible later.

What about voice, images and web search?

The buttons are on the HUD, but those features aren’t built yet: they show a “coming soon” notice. Text and code file attachments work today.

I found a bug. Where do I report it?

Write to nxtorbis@gmail.com. Include what you typed, what you expected, and what the activity panel logged.
